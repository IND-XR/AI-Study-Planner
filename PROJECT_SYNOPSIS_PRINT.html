1. Project Title

AI Powered Study Planner (SaaS) – Intelligent Study Timetable Generation and Progress Analytics for College Students

2. Introduction

Students frequently encounter difficulty in planning and managing study schedules across multiple subjects, exams, and topic-level coverage. Manual planning is time-consuming and often fails to adapt to factors such as exam dates, subject weightage, topic difficulty, available study hours, and consistency of study habits.

This project proposes a SaaS-based web application that provides structured academic organization (Subjects → Exams → Topics) and generates an optimized study plan within a selected date range. The system also offers progress tracking and analytics at daily/weekly/monthly levels. The application is implemented with a Next.js (TypeScript) frontend and a NestJS (TypeScript) backend, supported by PostgreSQL persistence and Prisma ORM for data modeling and integrity.

3. Problem Statement

Design and implement a secure, scalable SaaS system that helps college students:

  • Organize academic content as subjects, exams, and topics.
  • Prioritize preparation based on exam urgency, weightage, and topic difficulty.
  • Generate feasible study timetables within the student’s available time constraints.
  • Track progress using study logs, statistics, and study streak analysis.
  • Maintain secure authentication and user-data isolation in a multi-tenant environment.

4. Objectives of the Project

  • Develop a multi-user SaaS web application with secure authentication.
  • Provide CRUD management for subjects, exams, and topics.
  • Implement an intelligent study plan generation algorithm that allocates hours across topics based on exam proximity, exam weightage, topic difficulty, topic priority, and estimated hours.
  • Provide plan activation and plan-level progress computation.
  • Provide progress logging and analytics endpoints (daily/weekly/monthly statistics and streaks).
  • Use a maintainable, modular architecture suitable for future enhancements, including AI/ML-based optimization.

5. Scope of the Project

In Scope

  • Authentication and authorization using JWT with protected routes via guards.
  • Academic management: Subjects, Exams, Topics (relationships enforced via Prisma).
  • Study plan generation within a user-defined date range and daily/weekly hour limits.
  • Study plan lifecycle: generate, list, fetch active plan, activate plan, compute progress metrics.
  • Progress tracking: study logs and analytics (daily/weekly/monthly stats, streaks).
  • Security and reliability: throttling, global validation, global exception handling, CORS/Helmet middleware.

Out of Scope (Current/Planned)

  • Full ML model integration (architecture includes placeholders for future integration).
  • SaaS billing/subscriptions (future extension).
  • Native mobile app (future enhancement).

6. Proposed System / Solution

The solution is implemented as a two-part system: (i) a Next.js frontend that provides UI flows and consumes REST APIs via a centralized client, and (ii) a NestJS backend that provides validated and secured endpoints, orchestrates the planning algorithm, and persists data through Prisma + PostgreSQL.

The planning engine uses algorithmic prioritization and distribution strategies to allocate available hours across topics and dates while preventing overload on any single day. The backend codebase also includes a dedicated generator abstraction to support future ML-based personalization.

7. Technologies Used

Frontend

  • Next.js 14, React 18, TypeScript
  • Tailwind CSS
  • Axios (API integration), Zustand (state management)
  • Lucide icons; Recharts (dashboard visualization)

Backend

  • NestJS (TypeScript), modular controllers/services/DTO validation
  • JWT authentication (Passport JWT + Nest JWT), bcrypt password hashing
  • Helmet, CORS, Throttling, Global exception handling and interceptors
  • Nodemailer and Supabase service modules (foundation for notifications/integrations)

Database

  • PostgreSQL with Prisma ORM (schema, migrations, constraints, indexes)

8. System Architecture (based on the code structure)

The backend follows a modular NestJS architecture with feature modules (auth, user, subject, exam, topic, study-plan, progress). Cross-cutting concerns are implemented in a common layer (guards, decorators, interceptors, filters). Data access is centralized via a Prisma service module. The frontend follows the Next.js App Router structure with reusable components, a centralized API client, and a lightweight auth store.

9. Methodology / Development Approach

  • Iterative development with feature-based modularization
  • Database design-first implementation using Prisma models and migrations
  • API-first backend design with DTO validation and guard-protected routes
  • Frontend integration through a centralized Axios client and state store
  • Algorithmic planning engine with configurable distribution strategies and load balancing

10. Features of the System

  • JWT-based authentication and role-ready user model (ADMIN/STUDENT)
  • CRUD operations for subjects, exams, and topics with relational integrity
  • Study plan generation based on urgency, weightage, difficulty, priorities, and available hours
  • Study plan lifecycle: active plan retrieval, activation, and plan progress computation
  • Progress logging with daily/weekly/monthly stats and study streak analysis
  • Production-grade backend middleware: validation, throttling, Helmet, CORS, exception filters

11. Expected Outcomes

  • Students can create structured academic datasets and personalized schedules.
  • Optimized study timetables aligned with exam timelines and time availability are generated.
  • Students receive analytics-driven insights about consistency and preparation progress.
  • The modular architecture supports scaling into a production SaaS offering.

12. Future Enhancements

  • ML-based personalization (adaptive re-scheduling, performance prediction)
  • Automated reminders (email/push) and smart notifications
  • Subscription billing for SaaS monetization
  • Advanced calendar UI with drag-and-drop schedule editing and conflict resolution
  • Admin dashboards and institutional integrations

13. Conclusion

The AI Powered Study Planner (SaaS) offers an end-to-end solution for exam preparation planning by combining a modern full-stack architecture (Next.js + NestJS), a structured relational data model (PostgreSQL + Prisma), and an algorithmic planning engine. The system enhances planning efficiency, supports measurable progress tracking, and provides a scalable foundation for future AI-driven personalization.
